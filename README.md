NOVO SITE LGE BRASIL
====================

Site estático (HTML + CSS puro) — 19 páginas, otimizado para Google e motores de
busca por IA (llms.txt, robots.txt com GPTBot/PerplexityBot/ClaudeBot liberados).

Publicação
----------
- GitHub Pages: este repositório serve o site direto da branch main.
- Netlify: arraste a pasta `site/` em app.netlify.com (Deploy manually).
- Hospedagem própria: envie o conteúdo da pasta `site/` para o public_html.

Domínio de produção
-------------------
Apontar www.lgebrasil.com.br para este site (Netlify ou DNS do GitHub Pages)
e atualizar as URLs canônicas/sitemap para o domínio final.

Estrutura
---------
- index.html (Home)
- solucoes/ · 12 páginas de serviço · sobre/ · contato/ · areas-de-atuacao/
- css/style.css · img/ (fotos reais LGE + vídeo de obra)
- robots.txt · sitemap.xml · llms.txt · 404.html
